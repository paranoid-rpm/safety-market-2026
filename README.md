# SAFETY MARKET 2026

Многостраничный образовательный сайт по теме «Обзор ассортимента индивидуальных средств защиты на современном рынке».

## Страницы

- `index.html` — главная страница и обзор проекта;
- `catalog.html` — каталог СИЗ с фильтрами и раскрывающимися подробностями;
- `classification.html` — классификация, классы риска и нормативная база;
- `technology.html` — современные материалы, умные СИЗ, экзоскелеты и машинное зрение;
- `history.html` — интерактивная хронология развития СИЗ;
- `market.html` — масштаб рынка, тенденции, каналы поиска и ориентиры выбора СИЗ;
- `about.html` — паспорт проекта, задачи, методы и источники.

## Технологии

HTML5 + CSS3 + vanilla JavaScript. Внешние библиотеки, сборщик и сервер не требуются.

## Запуск

Сайт работает через GitHub Pages и может открываться локально без build step: достаточно открыть `index.html` в современном браузере.
